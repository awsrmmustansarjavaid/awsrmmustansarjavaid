# AWS Docker Lab

## Overview

A beginner-focused lab: clone a repo onto an EC2 instance, containerize the
app with Docker, and serve it publicly.

## What I Practiced

- EC2 instance setup
- Installing and running Docker
- Pulling application code from GitHub
- Basic security group configuration

## What I Learned

The full manual path from "empty EC2 instance" to "running containerized
app" before automating any of it — useful groundwork before introducing a
pipeline.
