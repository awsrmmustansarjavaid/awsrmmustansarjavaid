# Docker & RDS Lab

## Overview

Connects a Dockerized web application to a managed Amazon RDS database
instance instead of a local/container database.

## What I Practiced

- Amazon RDS setup and security groups
- Environment-variable based DB configuration
- Connecting a containerized app to an external managed database

## What I Learned

Why managed databases change your networking and security-group story
compared to running a database inside a container.
