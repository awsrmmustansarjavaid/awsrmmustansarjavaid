# AWS Hybrid IaC Lab

## Overview

Explores provisioning the same class of AWS infrastructure with two
different Infrastructure-as-Code tools, to compare their trade-offs
directly.

## What I Practiced

- Terraform modules and state management
- CloudFormation stacks and parameters
- Comparing declarative IaC approaches side by side

## What I Learned

Terraform's provider ecosystem versus CloudFormation's tighter native AWS
integration — and when each is the better fit for a given team.
