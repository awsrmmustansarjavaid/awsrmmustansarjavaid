# AWS EC2 Docker CI/CD Microservices Lab

A hands-on build covering a full microservices deployment loop on AWS EC2.

## Overview

Multiple small services are containerized, deployed to EC2, and wired into
a CI/CD pipeline with basic monitoring on top.

## What I Practiced

- Multi-service Docker Compose setups
- CI/CD pipeline triggers on push
- EC2 provisioning and networking
- Health checks and basic monitoring

## What I Learned

How to keep independently deployable services from becoming an
operational headache once there's more than one of them to manage.
