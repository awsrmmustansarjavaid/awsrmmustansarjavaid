# Charlie Cafe DevOps

An end-to-end AWS Cloud DevOps implementation for a sample cafe web application.

## Overview

This project takes a simple web app from source code to a fully automated,
containerized deployment on AWS — covering build, test, containerization,
and infrastructure provisioning.

## What I Practiced

- AWS infrastructure setup (VPC, EC2, IAM)
- Docker containerization
- CI/CD pipeline design
- Infrastructure as Code
- Basic monitoring and logging

## What I Learned

Coordinating multiple AWS services behind a single automated pipeline, and
structuring a repo so infrastructure and application code can evolve
independently.
