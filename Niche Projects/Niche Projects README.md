- ⭐ Favorite journeys

- 📤 JSON import and export

## 02. 🎬 Charlie MJ Drive Media Downloader

**A Browser Extension for Authorized Google Drive Media Workflows**

[![Repository](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github)](https://github.com/awsrmmustansarjavaid/charlie-MJ-drive-media-downloader)

### 💡 Project Overview

A Chrome/Chromium extension that simplifies identifying and opening media streams from Google Drive files the user is already authorized to access.

### ✨ Key Features

- 🎥 Automatic media detection
- 🎵 Video and audio stream detection
- 📊 File-size detection
- 🏷️ Quality and format labels
- 🧹 Byte-range parameter cleanup
- ♻️ Stream deduplication
- 📐 Sort streams by size
- ▶️ One-click stream opening
- 🪶 Lightweight browser extension
- 🔒 No external application server
- 🔒 No analytics

### 🛠️ Technologies

`Chrome Extension MV3` `JavaScript` `HTML5` `CSS3` `chrome.webRequest` `chrome.tabs` `Service Worker` `Chrome Runtime Messaging`

### ⚙️ Workflow

```text
Google Drive Video
        ↓
Browser Plays Media
        ↓
Media Network Requests
        ↓
chrome.webRequest
        ↓
Detect Video / Audio Streams
        ↓
Read Media Metadata
        ↓
Clean & Deduplicate Streams
        ↓
Display Available Results
        ↓
Open Authorized Stream
```

> **Security:** Designed for media accessible through the user's existing authorized browser session. It does not bypass authentication or access controls.

- Codec and FPS information

**🌐 Browser Capture**

- Edge-compatible architecture
- Browser page capture
- Media stream detection
- Google Drive media request detection
- Video/audio pairing
- Stream deduplication
- Download and Combine
- Watch Browser mode

**📥 Download Management**

- Download queue
- Priority management
- Pause and resume
- Cancellation and retry
- Concurrent downloads
- Progress and speed reporting
- Download history foundation
- SQLite foundation
- Temporary-file cleanup
- Download verification

4. Enable **Developer Mode**.
5. Select **Load unpacked**.
6. Choose the extracted folder containing `manifest.json`.
7. Open or refresh a YouTube video.

## 13. 📚 Charlie MJ Reader

**An Intelligent Browser-Based Reading, Knowledge Management & Productivity Extension**

[![Repository](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github)](https://github.com/awsrmmustansarjavaid/Charlie-MJ-Reader)

### 💡 Project Overview

A local-first Chrome Manifest V3 extension that turns ordinary web browsing into an organized reading, learning, and knowledge-management experience.

It combines distraction-free article reading, intelligent content capture, synchronized text-to-speech, vocabulary building, highlights, personal notes, reading analytics, website management, and productivity tools in one workspace. It works only on websites explicitly enabled by the user, keeping all other websites untouched.

### ✨ Key Features

- 📖 **Smart Article Reader** — Capture, organize, and read web articles in a dedicated workspace
- 🌐 **Supported Website Management** — Enable, disable, and configure individual websites and URL paths
- 🎯 **Floating Reading Toolbar** — Reading, vocabulary, productivity, and focus tools on supported websites
- 🔊 **Smart Audio Reader** — Text-to-speech with play, pause, resume, sentence navigation, speed, pitch, and voice controls
- 📝 **Smart Text Selection** — Select and save words, sentences, paragraphs, and custom text
- 📚 **Vocabulary Builder** — Save vocabulary with definitions, translations, pronunciation, examples, synonyms, and notes
- 🌍 **Language Learning Mode** — Translate selected text, explore vocabulary, and use grammar-category highlighting
- 💬 **Quote & Paragraph Collection** — Save meaningful quotes, paragraphs, lines, and passages
- 🖍️ **Smart Highlights** — Highlight and organize important content from supported websites and saved articles
- 📌 **Reading Position Bookmarks** — Restore progress when returning to an article
- 📊 **Reading Analytics** — Track progress, completion, history, and productivity statistics
- 🗂️ **Article Library** — Search, organize, edit, remove, import, export, and manage saved articles
- 📰 **Website & Newspaper Library** — Organize websites, newspapers, author profiles, categories, and favorite sources
- 🔍 **SEO & Website Intelligence** — Website information, on-page SEO checks, ranking data, and article audits
- 🎯 **Focus Mode** — Brightness, contrast, dimming, blur, and reading appearance controls
- ⏱️ **Productivity Tools** — Built-in Pomodoro timer, 80/20 timer, and native reading controls
- 🎨 **Custom Reading Experience** — Themes, fonts, font sizes, reading width, line height, and toolbar customization
- 🔔 **Smart Notifications** — Configurable position, duration, and per-event controls
- 📤 **Data Export & Backup** — Export articles, vocabulary, highlights, and saved content, with full JSON backup and restore
- 🔒 **Local-First Storage** — Reading data stored locally using Chrome storage
- 💤 **Website Sleep Mode** — Unsupported or disabled websites remain untouched

### 🛠️ Technologies

`Chrome Extension MV3` `JavaScript` `HTML5` `CSS3` `Chrome Storage API` `Chrome Tabs API` `Chrome Scripting API` `Service Worker` `Content Scripts` `Chrome Context Menus` `Web Speech API` `Speech Synthesis` `JSON` `DOM Manipulation` `SEO Analysis` `Local-First Architecture`

### ⚙️ Workflow

```text
   User Opens a Supported Website
                ↓
     Website Activation Gate
                ↓
        Article Detection
                ↓
     Floating Reading Toolbar
                ↓
     Capture Article Content
                ↓
         Reading Engine
                ↓
      ┌─────────┼──────────┐
      ↓         ↓          ↓
    Read      Listen     Capture
   Article    with TTS   Content
      │         ↓          ↓
      │     Highlight   Vocabulary
      │    & Auto-scroll  Quotes
      │         │       Paragraphs
      └─────────┼──────────┘
                ↓
        Reader Workspace
                ↓
        My Reading Library
                ↓
   Notes / Highlights / History
                ↓
      Analytics & Progress
                ↓
        Export & Backup
```

### 🔐 Privacy & Security

- Local-first data storage using `chrome.storage.local`
- Website activation controlled through Supported Websites settings
- Unsupported websites remain untouched
- No cookie manipulation or authentication bypass
- No paywall or quota bypass
- AI configuration is opt-in; article text is not sent to an AI service by the extension
- Translation sends selected text only when the user explicitly requests it
- No automatic GitHub synchronization; backup and export are user-controlled

**Architecture:** Modular JavaScript, Chrome Manifest V3, a shared reading engine, and a unified saved-article database.
